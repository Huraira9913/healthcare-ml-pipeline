# Healthcare ML Pipeline

End-to-end pipelines for medical prediction tasks commonly used in Data Science portfolios:

- Diabetes prediction
- Heart disease prediction
- Parkinson’s disease prediction

Each pipeline includes:
- Data loading & basic EDA
- Preprocessing (scaling, encoding)
- Model training + evaluation
- Optional Streamlit demo

Uses public-style datasets (sklearn or generated with realistic distributions).
